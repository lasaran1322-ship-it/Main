## 🛒 How to Place an Order (Customer)

### Step 1: Login
1. Select "Customer" from User Type dropdown
2. Click "Login" tab
3. Enter: `demo@customer.com` / `demo`
4. Click Login

### Step 2: Browse Restaurants
1. View all restaurants on home page
2. Use search bar to find specific restaurants or food
3. Click on category filters (All, Pizza, Burgers, Sushi, Salads)

### Step 3: View Restaurant Menu
1. Click "View Menu" on any restaurant card
2. See all menu items with prices
3. Read item descriptions

### Step 4: Add Items to Cart
1. Click "Add to Cart" on desired items
2. Quantity automatically increases/decreases
3. View cart total at bottom

### Step 5: Place Order
1. Click "Proceed to Checkout"
2. Confirm delivery address
3. Review order summary
4. Click "Place Order"

### Step 6: Track Order
1. Go to "Orders" in navigation
2. See active orders with real-time status:
   - Pending
   - Confirmed
   - Preparing
   - Ready
   - Out for Delivery
   - Delivered
3. View delivery partner details
4. See estimated delivery time

## 🔧 Troubleshooting

### Login Issues
- **Problem**: Cannot login
- **Solution**: Check if you're using correct credentials and selected correct user type

### Cart Not Showing Items
- **Problem**: Items not persisting in cart
- **Solution**: Ensure local storage is enabled in browser

### Order Status Not Updating
- **Problem**: Order status appears stuck
- **Solution**: Refresh the page to see latest updates

### Dashboard Not Loading
- **Problem**: Dashboard components not visible
- **Solution**: Clear browser cache and reload
